# Standing rules for every agent working in this repo
1. **Everything goes to the release branches and goes live, every session (owner, 2026-11-17).** `main` is the OpenEMR 8.x edition (2.x); `openemr-7.0` is the OpenEMR 7.0.x edition (1.x), and the two are never merged into each other. Whatever branch a session is told to work on, put each finished change on the release branch it belongs to (both, when a fix applies to both editions) and push as soon as it passes; never leave finished work only on a side branch. At the start of a session, check the remote for branches with commits not on `main` / `openemr-7.0` and merge them unless they are superseded.
2. Only a very good reason keeps a change off the release branches (it would break an install, or needs an owner decision); say what it is in your reply.
3. Archway's EMR runs this module from the image `ghcr.io/mikebirkheadmd-maker/openemr-with-grapheus:8.4.1`; a release that should reach Archway also needs that image rebuilt and the server updated (see the TebraToOpenEMR repo).
